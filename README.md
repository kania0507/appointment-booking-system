# Appointment Booking System

A full-stack appointment booking system built from scratch with Symfony, React, TypeScript, Doctrine ORM, MariaDB, and Docker.

The project is designed as an educational full-stack application with a clear separation between frontend, backend, business logic, persistence, and infrastructure.

## Tech Stack

### Backend

- PHP 8.4
- Symfony 8.1
- Doctrine ORM
- Doctrine Migrations
- Symfony Validator
- Symfony Serializer
- MariaDB 11.8

### Frontend

- React
- TypeScript
- Vite
- React Router
- CSS / CSS Modules

### Infrastructure

- Docker
- Docker Compose
- Nginx
